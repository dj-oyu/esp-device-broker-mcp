# Private workspace staging checkpoint

`materialize_workspace` consumes a trusted in-process `WorkspacePlan` and yields
only a fully written and readback-checked scratch directory. It creates regular
copies, not links into source caches or receipt storage. Exit removes scratch,
including when the caller's build fails. Cancellation during preparation never
yields a partial workspace. This is temporary build state, not a durable receipt.

The initial adapter is POSIX only. It uses exclusive file creation, directory
handles, no-follow child opens, bounded portable inventories, and symlink-resistant
cleanup. Unsupported platforms fail closed. The caller must provide an existing
broker-owned local parent inaccessible to other writers, with trusted ancestors.
This helper neither establishes ACLs nor protects against hostile same-identity
processes. It is not a sandbox for untrusted build scripts. Stop and join all build
processes before exiting the context; artifact capture and retention are separate.

A planner identity is not an authorization credential. Remote requests must not
supply arbitrary plans, paths, or commands. The future broker adapter must verify
principal-owned source/private receipts, registration and recipe immediately
before staging, and retain ownership throughout execution and cleanup.

Tests use generated bytes only, including receipt ingestion, plan preparation,
staging, a fixed Python subprocess fixture, output hash verification and cleanup.
They also exercise cancellation, write failure, build failure, invalid inventory,
symlink escape rejection and unsupported-platform rejection. This is not an
ESP-IDF build, real private-input ingestion, Windows validation or hardware proof.

Still required: native Windows staging and race tests; the protected deployment
root; authenticated broker job integration; registered build-profile execution;
private artifact provenance/retention; same-head CI; and real-input verification.
No credentials, runtime configuration, private assets or device state are changed.
