# Exact Git source from transformed archives

GitHub archives may omit export-ignore files or apply eol conversion. When an archive cannot reconstruct the fixed commit tree (or contains Gitlinks), the importer obtains that exact tree by its SHA, validates regular blob/Gitlink paths and modes, and repairs missing or transformed regular files from fixed blob SHA URLs within the same registered repository. It validates response encoding/size and the actual Git blob SHA, then still reconstructs and compares the complete Git tree. No archive mismatch is ignored.

Redirects, symlinks, LFS, unsafe/aliased paths, duplicate tree entries, untracked archive files, truncated metadata, wrong blob SHA/size/encoding, and malformed replies fail closed. Upstream URL fields are never followed and application credentials are never added to these public requests. Existing principal/lease/cancellation and private-cache checks remain. Metadata/archive/blob response bytes share the 64 MiB total download bound; restored content shares the 256 MiB expanded and 100,000 file bounds. Discarded transformed bytes still count toward the expansion budget. All activity shares the same 180-second deadline. Old immutable receipts are not rewritten.
